## 4.3.2 Contoh Perbandingan Kode: Sebelum dan Sesudah Pengerasan

### Contoh: Penanganan Perlindungan CSRF Token pada Permintaan POST (`app.py`)

#### Sebelum Perbaikan (Rentan CSRF):
```python
# Kode Rentan: Seluruh form POST langsung diproses tanpa verifikasi token
@app.route('/sewa/buka', methods=['GET', 'POST'])
@login_diperlukan
def buka_sewa():
    if request.method == 'POST':
        # Penyerang dapat membuat situs berbahaya yang mengeksekusi POST ke rute ini
        create_transaction(request.form['nama_pelanggan'], ...)
```

#### Sesudah Perbaikan (Aman Terlindungi):
```python
# Kode Aman: Middleware memverifikasi kecocokan token sesi kriptografis
@app.before_request
def csrf_protect_middleware():
    if request.method in ("POST", "PUT", "DELETE", "PATCH"):
        token_sent = request.form.get("csrf_token")
        token_session = session.get("_csrf_token")
        if not token_session or not token_sent or token_sent != token_session:
            logger.warning(f"Validasi CSRF gagal untuk IP {request.remote_addr} pada rute {request.path}")
            return render_template("400_csrf.html", message="Token keamanan formulir (CSRF Token) tidak valid."), 400
```

*Analisis:* Perbaikan di atas memastikan setiap permintaan manipulasi data wajib menyertakan token acak kriptografis 32-byte berbasis sesi (`secrets.token_hex(32)`). Permintaan lintas situs tanpa token langsung ditolak dengan status HTTP 400 Bad Request sebelum menyentuh lapisan logika bisnis.
