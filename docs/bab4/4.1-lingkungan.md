# 4.1 Lingkungan Pengembangan dan Pengoperasian

Subbab ini menguraikan spesifikasi teknis lingkungan perangkat keras dan perangkat lunak yang digunakan selama siklus pengembangan sistem manajemen rental PlayStation **Exito Playbox**, konfigurasi server produksi, serta pernyataan etika penggunaan asisten kecerdasan buatan (*AI Assistant*).

## 4.1.1 Spesifikasi Perangkat dan Dependensi Perangkat Lunak

Pengembangan aplikasi web Exito Playbox dilaksanakan pada komputer lokal pengembang dengan spesifikasi yang terstandardisasi untuk menjamin portabilitas saat dideploy ke komputer gerai rental klien.

### Tabel 4.1: Spesifikasi Lingkungan Perangkat Keras dan Perangkat Lunak

| Komponen Lingkungan | Spesifikasi Teknis / Versi | Peran dalam Proyek |
|---|---|---|
| **Sistem Operasi Pengembangan** | Windows 11 Home 64-bit (Build 22631) | Lingkungan utama pengkodean dan pengujian otomatis |
| **Sistem Operasi Target Klien** | Windows 10 Pro 64-bit / Linux Ubuntu 22.04 LTS | Komputer kasir dan server lokal gerai Exito Playbox |
| **Bahasa Pemrograman** | Python 3.10+ / Python 3.14 (Virtual Environment `.venv`) | Bahasa utama logika bisnis, controller, dan pengujian |
| **Engine Basis Data** | SQLite versi 3.45+ (Pustaka bawaan `sqlite3`) | Penyimpanan relasional lokal dengan penegakan *Foreign Key* |
| **Server Produksi WSGI** | Waitress versi 3.0.2 | Server HTTP produksi berkinerja tinggi multi-threaded |
| **VCS & Kolaborasi** | Git 2.40+ dan GitHub Repositories | Pelacakan versi kode, branching fitur, PR, dan rilis tag |

## 4.1.2 Pernyataan Etika dan Peran Asisten Kecerdasan Buatan (AI)

Dalam pengembangan proyek ini, tim pengembang memanfaatkan asisten kecerdasan buatan berbasis *Large Language Model* (Claude 3.7 Sonnet / Antigravity Agent DeepMind) dengan pendekatan **Vibe Coding Terkendali** (*Human-in-the-Loop*). 

### Prinsip dan Cara Pemakaian AI:
1. **Peran AI:** Asisten AI difungsikan sebagai generator draf awal kode fungsi, pembantu perumusan kasus uji parametris, dan penyusun kerangka dokumentasi. AI tidak pernah diberi wewenang tunggal untuk langsung menggabungkan kode ke repositori utama.
2. **Konteks Terarah (*Context-Driven Prompting*):** Setiap instruksi prompt selalu menyertakan konteks skema basis data [docs/desain/schema.sql](file:///c:/Users/maaru/Documents/rpl-project-ps/docs/desain/schema.sql) dan batasan arsitektur tiga lapis agar kode yang dihasilkan tidak mengalami halusinasi nama tabel atau kolom.
3. **Audit Kritis dan Pengujian Mandiri:** Seluruh kode yang dihasilkan AI diaudit baris demi baris terhadap standar keamanan OWASP Top 10, diverifikasi melalui pengujian mutasi (*mutation testing*), dan wajib lulus seluruh rangkaian pengujian otomatis `pytest` sebelum di-commit.
4. **Transparansi Interaksi:** Seluruh siklus prompt, respon AI, keputusan pengembang (Terima, Ubah, atau Tolak), serta refleksi teknis dicatat secara jujur pada dokumen [jurnal-vibe-coding.md](file:///c:/Users/maaru/Documents/rpl-project-ps/jurnal-vibe-coding.md).
