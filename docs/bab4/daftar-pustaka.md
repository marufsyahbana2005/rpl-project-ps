## Pernyataan Penggunaan Kecerdasan Buatan (AI Usage Statement)

Laporan tugas besar ini disusun dengan memanfaatkan bantuan kecerdasan buatan (*Generative AI Assistant*). Pernyataan etika dan akuntabilitas akademik dijabarkan sebagai berikut:

1. **Kakas AI yang Digunakan**: Google Antigravity AI Assistant berbasis model Gemini.
2. **Peran Kakas AI**: 
   - Membantu penyusunan kerangka struktur dokumen awal (*drafting*).
   - Memeriksa konsistensi tata bahasa, ejaan baku Bahasa Indonesia, dan kejelasan alur narasi teknis.
   - Mengotomatisasi ekstraksi rekapitulasi data log jurnal vibe coding via skrip Python.
3. **Peran dan Tanggung Jawab Anggota Pengembang**:
   - Berperan sebagai perancang arsitektur, penguji mandiri, dan penyunting utama (*human-in-the-loop*).
   - Memvalidasi seluruh kode sumber, konfigurasi deployment, serta keabsahan data empiris pengujian secara faktual di terminal.
   - Bertanggung jawab mutlak 100% atas seluruh isi, klaim teknis, keabsahan data, integritas kode, dan orisinalitas dokumen laporan akhir ini tanpa ada penyerahan tanggung jawab kepada kakas AI.
